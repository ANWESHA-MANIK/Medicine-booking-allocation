## Project Overview

This project aims to develop a medicine booking and allocation module for pharmacy applications. The system prioritizes medicine booking requests based on defined priority rules, medicine availability, urgency, and permitted patient-history information.

It supports medicine search, booking requests, prescription verification workflows, inventory management, priority-based stock allocation, waitlist management, notifications, and administrative operations.

The system is intended to support booking and allocation. It does not diagnose diseases, prescribe medicines, or independently modify a doctor's prescription.

## Main Features

- User registration, authentication, and role-based access control
- Medicine search and availability checking
- E-prescription attachment and verification workflow
- Priority calculation and booking allocation
- Inventory quantity management and reservation
- Waitlist creation and management
- Booking and waitlist status notifications
- Administrative functions and audit records

## Scope and Safety

The module must enforce appropriate access controls, protect prescription information, verify prescription requirements before applicable fulfilment, and prevent duplicate or unsafe inventory allocation.

Priority rules must be deterministic and documented. The system must not make diagnoses or change a doctor's prescription.
